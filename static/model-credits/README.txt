Renders generated from the installed Cobblemon 1.8.2 models, plus Mega Showdown 1.3.1 and ATM x MSD v5.0 for species not supplied by the base JAR.
Original geometry, textures and idle animation poses were rendered offline with Three.js. The wiki ships static WebP renders, without an interactive model viewer or game JARs.
Per-species source paths and model hashes: sources.json. Original per-model license/credit files are retained alongside this file where supplied by the source package.
Cobblemon: https://cobblemon.com/ and https://gitlab.com/cable-mc/cobblemon
Mega Showdown: https://modrinth.com/mod/mega-showdown
Pokemon and character designs belong to their respective owners.

Trainer renders use the original Minecraft skins provided by @mottameister for the campaign. Tokito uses the existing campaign mod skin. Motta’s hero artwork uses Motta_GymLeader_Dragon.png. Source file names and hashes: trainer-skins.json.
